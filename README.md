# הזמנת מגרש טניס בדפנה (גרסת Vercel)

שעות של 60 דקות, עד שבוע מראש, חינם לתושבים. כולם רואים בזמן אמת מה פנוי, מה תפוס, מי מחפש שותף ומתי יש חוג.

## מבנה

| קובץ | תפקיד |
|---|---|
| `public/index.html` | הדף (סטטי) |
| `api/index.js` | כל ה־API בפונקציה אחת, ללא תלויות |
| `vercel.json` | ניתוב, כותרות אבטחה, אזור `fra1`, ניקוי יומי (Cron) |

הנתונים נשמרים ב־**Upstash Redis** (מפתחות עם הקידומת `tennis:`). השעות מחושבות תמיד לפי שעון ישראל.

## העלאה ל־Vercel

1. **פריסה ראשונה** (מתוך התיקייה הזו):
   ```bash
   npx vercel --scope dafna6
   ```
   לשם הפרויקט: `dafna-tennis`. לשאלות ההגדרה עונים Enter (ברירות המחדל נקראות מ־`vercel.json`).
   אפשרות אחרת: להעלות לריפו ב־GitHub ולייבא דרך Add New → Project.
2. **מסד נתונים:** בפרויקט, Storage → Create Database → Upstash (Redis) → תוכנית Free, אזור Frankfurt → Connect to project.
   החיבור מוסיף אוטומטית את `KV_REST_API_URL` ואת `KV_REST_API_TOKEN`.
3. **משתני סביבה:** Settings → Environment Variables:
   - `ADMIN_PASSWORD`: סיסמת מנהל (חובה, לפחות 6 תווים)
   - `CRON_SECRET`: מחרוזת אקראית ארוכה (מומלץ, מגן על נקודת הניקוי)
4. **פריסה לייצור:** `npx vercel --prod --scope dafna6`. משתני סביבה נכנסים לתוקף רק בפריסה חדשה.

## הגדרות אופציונליות (משתני סביבה)

| משתנה | ברירת מחדל | משמעות |
|---|---|---|
| `OPEN_HOUR` / `CLOSE_HOUR` | 7 / 22 | שעות פעילות |
| `DAYS_AHEAD` | 7 | כמה ימים קדימה אפשר להזמין |
| `GUEST_PRICE` | 100 | מחיר לאורחים (₪, מוצג בלבד) |
| `COURT_NAME` | המגרש | שם המגרש |
| `MAX_PER_DAY` | 0 | מקסימום הזמנות ליום לאדם (0 = ללא הגבלה) |

## חיסכון במכסות

- הדף מתרענן כל 30 שניות כשהוא גלוי, כל 5 דקות אחרי 15 דקות בלי מגע, ולא בכלל כשהלשונית מוסתרת.
- כל רענון הוא קריאה אחת לפונקציה וקריאה אחת ל־Redis (6 פקודות).
- גם מסך שדולק כל הזמן מייצר כ־9,000 קריאות בחודש. בשימוש רגיל מדובר באחוזים בודדים מהמכסה החינמית.

## איך זה עובד

- **תושבים:** בלי הרשמה. כל מכשיר מקבל מזהה אנונימי, ורק הוא יכול לבטל את ההזמנות שלו.
- **מנהל:** "כניסת מנהל" בתחתית הדף. אחרי 10 ניסיונות כושלים נחסמים ל־15 דקות. ההתחברות תקפה ל־30 יום.
- **הזמנה כפולה:** לא אפשרית, גם כששני אנשים לוחצים באותו רגע (נאכף ב־Redis עם `HSETNX`).
- **ניקוי:** פעם ביום נמחקות הזמנות וחסימות מימים שעברו.

## פרטיות

- טלפון של מזמין גלוי רק לו ולמנהל. בקשת הצטרפות גלויה רק למזמין ולמנהל.
- ברשימת "רוצים לשחק" הטלפון גלוי לכל מי שפותח את הדף.
- הסימון "תושב דפנה" מבוסס אמון, בלי אימות.
